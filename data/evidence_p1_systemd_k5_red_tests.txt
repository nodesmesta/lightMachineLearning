RED Test Cases Added
--------------------
1. test_systemd_first_chunk_timeout_uses_stream_bound
   Requirement:
     A worker that never emits the first chunk within
     stream_first_chunk_timeout must terminate with StreamTimeout(reason=
     "first_chunk").

2. test_systemd_idle_timeout_uses_stream_bound
   Requirement:
     A worker that emits one chunk and then stalls beyond stream_idle_timeout
     must terminate with StreamTimeout(reason="idle").

3. test_systemd_total_timeout_uses_monotonic_absolute_deadline
   Requirement:
     A worker that keeps sending chunks within the socket inactivity timeout
     must still be stopped by stream_total_timeout.

4. test_systemd_adapter_error_frame_is_not_returned_as_chunk_data
   Requirement:
     An adapter/runtime error encoded as internal error must not be yielded as
     normal chunk data.

5. test_systemd_abnormal_eof_before_terminal_frame_fails_closed
   Requirement:
     EOF before an explicit completed/error terminal frame must fail closed.

6. test_systemd_restart_during_active_stream_raises_stream_restarted
   Requirement:
     Restart during an active systemd stream must invalidate the old stream and
     raise StreamRestarted instead of completing normally.

7. test_systemd_client_cancellation_does_not_leave_worker_busy
   Requirement:
     Client cancellation must trigger bounded lifecycle action on the affected
     worker instead of leaving the production worker stream unmanaged.

8. test_systemd_slow_consumer_has_bounded_behavior
   Requirement:
     A slow consumer must not result in silent unbounded/indefinite systemd
     stream behavior.
