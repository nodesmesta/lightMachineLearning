Public protocol corrections:
  - Core now rejects Accept: application/x-ndjson requests with {"inputs": [...]}
    at the edge with HTTP 400 JSON before invoking host.stream().
  - Unsupported streaming is mapped to a controlled NDJSON worker_error with
    code 400 and message "streaming not supported".

Production-path slow-consumer correction:
  - SystemdTransientWorkerHost.stream() reads stream_backpressure_timeout from
    resource_limits.
  - After yielding a chunk, it measures how long the consumer takes to request
    the next item.
  - If the consumer stalls beyond stream_backpressure_timeout, it closes the
    worker connection and raises StreamBackpressure instead of continuing
    silently.
