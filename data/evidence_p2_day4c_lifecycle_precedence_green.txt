Implementation summary
======================

P2 keeps the Day 4B systemd streaming model intact and changes only lifecycle
precedence inside SystemdTransientWorkerHost.stream().

The fix adds a local helper:
  _raise_if_stream_stale()

The helper reuses the existing stream identity snapshot:
- stream_unit
- stream_launch_count
- stream_secret

The helper is called:
- before each read-loop iteration interprets state;
- immediately after line = resp.readline() returns successfully;
- before accepting a chunk frame;
- before accepting a completed frame;
- before abnormal EOF is reported as protocol failure;
- before socket.timeout is converted to StreamTimeout;
- before ConnectionRefusedError, ConnectionResetError, or OSError is converted
  to WorkerNotReady.

Behavior intentionally preserved when the stream is not stale:
- first-chunk, idle, and total timeout still raise StreamTimeout;
- non-terminal EOF still fails closed;
- transport failure still maps to WorkerNotReady;
- adapter error and malformed protocol behavior remain unchanged;
- public server mapping remains unchanged.
